## About the Project

This project is part of my JavaScript learning journey. The goal is to practice JavaScript fundamentals by building an interactive Rock Paper Scissors game.

The project focuses on using JavaScript to handle user input, generate the computer's choice, compare choices, determine the winner, and update the webpage.

## Features

* Player can choose Rock, Paper, or Scissors
* Computer generates a random choice
* Displays the result of each round
* Keeps track of the score
* Displays the current game result
* Allows the player to play multiple rounds
